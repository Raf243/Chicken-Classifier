# Chicken Breed Classifier
This is a binary classifier that distinguishes local congolese chicken from broiler chicken using a deep neural network built form scratch using Numpy.

## Built by
Rafiki Kasarabu - Eastern DRC.

## Datasets
176 local breed images (collected personally).
156 broiler images (collected online using Google Search).

## Tech Stack
Python
Numpy
Matplotlib
Gradio
FastAPI
